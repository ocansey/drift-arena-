    STAGE 01

    Shadow scoring

    Every authorization is scored by both models, so the challenger is measured on 100% of traffic from day one. Only the arm a transaction is routed to actually decides the outcome, so an unproven model is evaluated at full statistical power while risking only its allocated slice.

    STAGE 02

    Drift detection

    Each input feature is binned against the distribution captured at training time and scored with PSI = Σ (aᵢ − eᵢ) · ln(aᵢ/eᵢ). Two or more features crossing 0.25 fires the alarm — before the loss shows up in a weekly report.

    STAGE 03

    Adaptive allocation

    A drift alarm rebalances traffic from 90/10 to 50/50. Under a shifting distribution the cost of running an under-powered test is higher than the cost of exposing more traffic to the challenger, so the split follows the evidence.

    STAGE 04

    Gated promotion

    Because both models judge the same authorizations, the outcomes are paired — so the gate is McNemar’s test on discordant pairs, not a two-proportion z-test that would assume independence it does not have. Promotion fires at p < 0.01.
